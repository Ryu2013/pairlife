# ペアライフ (PairLife)

二人で使う割り勘家計簿アプリ「ペアライフ」の一般公開に向けたリリース計画・設計ドキュメント・ソースコードを管理するリポジトリ。

前身は夫婦二人用に作った個人アプリ「べびーず」(GitHub Pages + Google Apps Script + スプレッドシート)。
本リリースではスプレッドシート / GitHub Pages を廃止し、インフラを AWS で一新する。

## 前提

- 対象は **二人組 (カップル・夫婦など) 専用**
- インフラは AWS

## ディレクトリ構成

工程ごとにディレクトリを分けて管理する。

| ディレクトリ | 内容 |
|---|---|
| `要件定義/` | 現状分析、機能要件・非機能要件 |
| `基本設計/` | システム構成、画面設計、データモデル、API設計 |
| `詳細設計/` | モジュール単位の設計 |
| `開発/` | ソースコード |
| `単体テスト/` | 単体テスト計画・結果 |
| `結合テスト/` | 結合テスト計画・結果 |
| `性能テスト/` | 性能テスト計画・結果 |
| `運用保守/` | 運用手順、監視、障害対応 |

## 注意

このリポジトリは **Public** です。AWS の認証情報、アカウントID、`.env`、Terraform の state ファイルなどの秘密情報はコミットしないこと。
